ОБНОВЛЕНИЕ УЖЕ РАБОТАЮЩЕГО САЙТА С IPHONE
1. Скачай и распакуй ZIP в приложении «Файлы».
2. Открой GitHub в Safari и перейди в репозиторий master-otdelki.
3. Нажми Add file -> Upload files. Загрузить нужно содержимое папки проекта, не ZIP.
4. В первую очередь замени index.html и sw.js файлами из версии 0.5. Если GitHub предложит загрузить файлы с теми же именами, подтверди замену/commit. Можно загрузить также README.txt; остальные конфигурационные файлы менять не обязательно.
5. Нажми Commit changes.
6. Render обычно автоматически запустит новый deploy после commit. Открой Render -> master-otdelki -> Events и дождись успешного deploy/Live.
7. Открой сайт и обнови страницу. Если видишь старую версию, закрой вкладку и открой сайт заново; на iPhone может потребоваться обновить страницу ещё раз, чтобы service worker заменил кэш.

ВАЖНО ПРО ДАННЫЕ
- Не удаляй данные сайта и не нажимай «Удалить все локальные данные». Данные хранятся в браузере конкретного устройства.
- Перед обновлением на всякий случай открой Настройки -> Экспортировать резервную копию.
- Если открываешь приложение через другую ссылку, другой браузер или очищаешь данные Safari, объекты и сметы могут не появиться автоматически.
- Видео открываются через поиск YouTube по теме инструкции. Сами ролики принадлежат их авторам и доступность зависит от YouTube.
- Текстовые инструкции являются базовыми ориентирами. Следуй техкарте конкретного материала и правилам безопасности.
